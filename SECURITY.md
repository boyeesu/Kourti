# Security policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public GitHub issues,
Discussions, pull requests, or commits. Email details to info@kourti.com with
the subject line `SECURITY: Kourti Legal`.

Include a clear description, affected component/version, reproduction steps,
impact, and any suggested mitigation. Do not include customer data or working
credentials.

We aim to acknowledge reports within five business days and will coordinate a
fix and disclosure timeline with the reporter. We may ask for additional
information to reproduce the issue.

## Supported versions

Security fixes are applied to the current `main` branch and the latest tagged
release. Self-hosters should keep dependencies current and apply releases
promptly.

## Deployment responsibilities

Operators are responsible for production TLS, secure secrets, access control,
database backups, dependency updates, and applicable data-protection and legal
requirements. Kourti Legal is software, not legal advice.
